## 尚未驗證

- 人工聽讀的發音、斷句、速度與音質。
- 實體手機／iPad 分享選單、存入相簿、實際 FPS；觸控模擬僅驗版面和程式流程。
- 桌機及 CPU 節流 FPS 未量測；無性能數字宣稱。
- 部署未執行；目前為本機與 GitHub 程式交付。

現有模型無骨架、腿部或坐姿動畫；角色以位置移動呈現登船與下船。學習紀錄僅存在目前瀏覽器及來源網址。
